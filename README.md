# 📋 오늘의 할 일 (To-Do List)

깔끔하고 직관적인 디자인의 반응형 할 일 관리 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **할 일 기본 관리 (CRUD)**
   - 빠른 추가 (Enter 키 지원)
   - 인라인 수정 (할 일 더블클릭 또는 연필 아이콘)
   - 완료 토글 (체크박스 애니메이션 및 취소선)
   - 개별 삭제 및 완료된 항목 일괄 삭제

2. **분류 & 우선순위 & 마감일**
   - **우선순위 3단계**: 높음(🔥), 보통(⚡), 낮음(🌱)
   - **카테고리 태그**: 개인, 업무, 공부, 건강, 기타
   - **마감일 & D-Day 뱃지**: 오늘 마감, D-1, 지남 등 시각적 강조

3. **필터링 & 정렬 & 검색**
   - 상태별 필터: 전체 / 진행 중 / 완료됨
   - 카테고리별 태그 칩 필터
   - 실시간 키워드 검색
   - 정렬: 최신 등록순 / 오래된순 / 마감일 임박순 / 중요도 높은순

4. **생산성 & 편의 기능**
   - **오늘의 달성률 프로그레스 바**: 진행 상황(완료/전체, %) 실시간 반영
   - **다크 모드 지원**: 라이트/다크 테마 토글 (브라우저 저장)
   - **로컬 스토리지 연동**: 별도 로그인 없이도 데이터가 브라우저에 안전하게 보관
   - **데이터 백업 및 복원**: JSON 파일 내보내기/가져오기 기능

---

## 🚀 실행 방법

### 개발 서버 실행
```bash
npm run dev
```
터미널에 표시되는 로컬 주소(예: `http://localhost:5173`)로 접속하시면 됩니다.

### 빌드 및 미리보기
```bash
npm run build
npm run preview
```
